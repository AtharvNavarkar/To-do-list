# To-do-list

This is a simple To-Do List web application made using JavaScript.
It helps users add tasks, mark them as completed, and delete them.
All tasks are saved in the browser using LocalStorage, so they are not lost when the page is refreshed.

Features
    Add new tasks
    Mark tasks as completed by clicking on them
    Delete tasks using the delete button
    Tasks are saved automatically in the browser
    Tasks stay even after refreshing the page.

Technologies Used
    HTML – for structure
    CSS – for styling
    JavaScript – for functionality
    LocalStorage – to store tasks.

How it Works
    When the page loads, the app gets all saved tasks from LocalStorage.
    When you enter a task and click Add, it is added to the list.
    Clicking on a task marks it as completed.
    Clicking the Delete button removes the task.
    Every change is saved automatically in LocalStorage.
